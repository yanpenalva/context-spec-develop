# Prompt Contract: Release and Deploy

## Inputs

Approved verification/review, project delivery and observability context, and the intended release target.

## Produce

`release.md` with readiness checklist, approvals, migration/data impact, feature flags, communication, rollback trigger/procedure, smoke test, observation window and escalation owner.

## Constraints

Use provider-neutral language. Do not invent deploy commands or authorize production on behalf of the release owner.
