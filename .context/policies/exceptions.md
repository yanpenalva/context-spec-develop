# Policy Exceptions

An exception is a bounded decision to deviate from a MUST or SHOULD because the normal control is not currently feasible or would create greater risk.

Exceptions MUST:

- identify the exact policy and scope;
- explain evidence, rationale and risk;
- define compensating controls;
- name owner and approver;
- include creation and expiration dates;
- be referenced by affected work items;
- be reviewed before expiration.

An exception is not permission to ignore a finding indefinitely. Expired, revoked or unapproved exceptions do not satisfy a gate.
