# RTK Guidance

Use `rtk` as the preferred command wrapper when installed. It reduces noisy output so agents retain useful context.

- Prefer concise searches and targeted file slices over whole-repository dumps.
- Capture exact test and validation results in work-item evidence.
- Use ordinary commands when RTK is unavailable; tool absence is not a reason to skip validation.
- Never let output compression hide a failure, warning, destructive command or approval boundary.
