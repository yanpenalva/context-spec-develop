# Acme Orders example

Acme Orders is a fictional order-tracking service used to demonstrate the four Support/Product paths without exposing a real project.

| Item | Track/type | Demonstrates |
| --- | --- | --- |
| `FEAT-1001` | Product/feature | Discovery through learning |
| `BUG-2001` | Support/bug | Reproduction and normal fix |
| `INC-3001` | Support/incident | Containment without code change |
| `HOT-4001` | Support/hotfix | Urgent fix with rollback and postmortem |

Each directory contains a compact work-item record and points to the corresponding templates in the repository root.
