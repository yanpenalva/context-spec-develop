# Operating Model

## Product roles

- Product owner: problem, audience, scope and success criteria.
- Engineering owner: technical plan, implementation and test evidence.
- Reviewers: independent checks for architecture, security, data and operations when relevant.
- Release owner: production readiness and authorization.

## Support roles

- Reporter or service desk: initial signal and customer context.
- Triage owner: classification, priority and next action.
- Incident commander: impact, coordination and communication during an incident.
- Technical lead: diagnosis, mitigation and fix.
- Release owner: production change approval.
- Postmortem owner: systemic learning and action tracking.

One person may hold multiple roles in a small team, but approval gates must remain explicit.

Conversation profiles help an agent emphasize the right questions for these roles. They are not RACI assignments: the work item owner, reviewer and production approver remain human and explicit.
